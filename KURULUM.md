# Ahşap Tycoon v2.1 — Kolay Kurulum

Bu sürümde klasör yoktur.

## GitHub'a yükleme

1. ZIP dosyasını bilgisayarında çıkar.
2. Çıkan klasörün içindeki bütün dosyaları seç.
3. GitHub deposunda **Add file → Upload files** seç.
4. Bütün dosyaları yükleme alanına bırak.
5. **Commit changes** düğmesine bas.

Dosyalar deponun ana sayfasında yan yana görünmelidir.

## Firebase'de kalan iki adım

### 1. Firestore kuralları

1. Firebase Console'da **Firestore Database** bölümünü aç.
2. Üst tarafta **Rules** sekmesine bas.
3. Bu paketteki `firestore.rules` dosyasını Not Defteri ile aç.
4. İçeriğin tamamını kopyala.
5. Firebase'deki mevcut kuralların yerine yapıştır.
6. **Publish** düğmesine bas.

### 2. Yetkili alan adı

1. Firebase Console'da **Authentication** bölümünü aç.
2. **Settings → Authorized domains** bölümüne gir.
3. Şunu ekle:

`alcancraft.github.io`
